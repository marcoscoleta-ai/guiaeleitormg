O que é esta ferramenta?
Esta ferramenta é uma sugestão de pesquisa para as Eleições Gerais de 2026 — não constitui recomendação de voto. Informe seu CEP para ver o perfil da sua cidade, selecione os critérios e receba 5 candidatos por cargo: os 3 melhor pontuados nos seus critérios (azul) e os 2 mais bem posicionados nas pesquisas (roxo).

Os cargos são apresentados sequencialmente: escolha um candidato para desbloquear o próximo cargo.

⚠ Limitação de acesso a dados (CORS)

Algumas APIs públicas bloqueiam requisições diretas do navegador. Execute no terminal (requer Node.js):

npx cors-anywhere

Ou instale a extensão "CORS Unblock" no navegador.

⚠ Estado fora do escopo atual: Esta versão cobre os cargos estaduais apenas para Minas Gerais. Para o seu estado, os cargos estaduais exibirão os dados de MG como referência. O cargo de Presidente é nacional e exibido normalmente para todos os estados.
